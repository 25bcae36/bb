How it works

Borrow it. Lend it. Keep track.

Borrow

Find it, then ask for it

Search for what you need, check that it is available and send a request to the owner.

Lend

List what you are not using

Add a photo and a pickup spot for things you own, then accept or decline each request.

Track

Know what is due and when

Current borrowings, due dates, requests and returned items all stay in one place.

Why share

Affordability

Use something for the week you need it without paying to own it.

Resource sharing

One calculator can see ten exams instead of sitting in a drawer.

Fewer purchases

Less waste, and fewer things bought once and forgotten.

Community

Students helping students, a block away from each other.
